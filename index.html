Shortcut: 1 octal digit = 3 bits, 1 hex digit = 4 bits. 157₈ = 001 101 111₂ = 6F₁₆.

Two's complement in 3 steps

  1. Write +20 in 8 bits: 0001 0100
  2. Invert every bit: 1110 1011
  3. Add 1: 1110 1100 = −20
8 bits hold −128 … +127. The leftmost bit is the sign (1 = negative).

Memory trick

  • Prefix: operator comes pre (before) its operands.
  • Postfix: operator comes post (after).
  • Operands keep their left-to-right order in all three forms. If an option reorders a, b, c… it is wrong.
  • To find the outermost operator, find the one applied last (lowest precedence, outside all brackets).

Queue (FIFO)

enqueue at rear, dequeue at front. Used for BFS, print jobs, buffers. Circular index: (i+1) mod n.

Linked list

Each node = value + next. Insert/delete by relinking pointers, O(1) once found; search is O(n).

Candidate key finder

Single-letter attributes. Write FDs like P->Q separated by commas. Defaults = official Q21.

Method: attributes that never appear on a right-hand side must be in every key. Start from them, compute the closure, and add one attribute at a time until the closure covers everything. Keep only minimal sets.

Normalisation ladder

1NF — atomic values, no repeating groups
2NF — 1NF + no partial dependency on part of a composite key
3NF — 2NF + no transitive dependency (key → A → B)

Mnemonic: "the key, the whole key, and nothing but the key."

Exam-day tracing habits

  • Draw a table: one column per variable. Write a new row each time something changes.
  • Circle the array index base (1 or 0) before you start.
  • For blanks, plug the question's own example into each option. Eliminate, don't derive.
  • For recursion, write calls going down and returned values coming back up.
  • Budget ≈ 5 minutes per Subject B question. If stuck at 7, mark a best guess and move on.
